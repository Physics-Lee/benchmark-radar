# 创建 HTML 计划笔记

## 做什么

在仓库下新建子文件夹 `notes/issue-511-neuro-bci/`，写入 `index.html`——把已评审的实施计划（AI for Neuroscience / BCI 支持，issue #511 第一切片）改写成一份自包含的 HTML 笔记。

## 笔记内容（已在上一轮计划中定稿）

- 页眉：标题、日期、负责人、issue 链接、状态（草案，2 个待确认决策点）
- 英文摘要框 + 中文一句话结论（TL;DR）
- §1 已实测基线：三层语料覆盖表、neuro/BCI 专项命中与缺口清单、漏斗归因表
- §2 设计决策 D1–D4 + D5 待确认决策表（导航时序、arXiv 类目范围）
- §3–5 三个 PR 的文件级改动清单（PR1 数据标签 / PR2 发现层词表与预算修正 / PR3 AI for Science tab 含 #512 的两个坑）
- §6 测量协议（种子清单核验 → 干跑 → 去留判定）
- §7 风险与对策表
- §8 CI 六步序列与执行顺序

## 技术形态

- 单文件、零外部依赖（无 CDN/字体/脚本），内嵌 CSS
- 响应式 + `prefers-color-scheme` 暗色适配 + 打印样式
- 中文正文、英文技术术语原样保留，符合仓库双受众沟通规范

## 不做什么

- 不改任何现有文件（config.yml、src/、site/、tests/ 全部不动）
- 不执行计划本身——仅产出笔记文件，实施仍待后续批准
