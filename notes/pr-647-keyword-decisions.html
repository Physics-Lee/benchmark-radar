三个问题如何做决定最终入组词行为变化验证与边界
01 / Review

测试通过，语义仍然可能错。

漏标 · 整条记录被否决

一个普通短语挡住了真证据

脑类器官论文 Using Brain Organoids to Explore Human Neurobiology 明确讨论神经生物学，却因摘要出现 “the brain like …” 而触发 brain[- ]like 排除规则。

旧机制把整条记录排除，连其他独立证据也一起丢掉。

误标 · 计算架构比喻

“brain” 不一定指生物脑

Omni Interaction Agent Technical Report 用 “cerebellum-brain collaborative framework” 描述系统架构。

裸 brain 足以触发入组，已有的几个比喻排除词没有覆盖这种说法。

误标 · 学科词歧义

电生理也可能属于心脏研究

一项心房颤动研究写到双心房的 “electrophysiological properties”，被 electrophysiolog 命中。

摘要没有出现既有排除词，心脏研究因此进入神经科学标签。

这些案例取自仓库历史快照。审查时的本地 PR 提交为 17cf73c；当时无法连通 GitHub，未确认远端是否已有更新。

02 / Conversation

真正改变方向的是“减少入口”。

“要不我们减少一些【入组关键词】，比如只保留 EEG、ECoG 之类的。这样也不用写很多的【出组关键词】。”用户提出的核心方向

  1. 先讨论如何修补三个错误

    初步方案是区分强弱证据、限定上下文范围，让排除词只影响局部命中。但规则会变得更复杂，也需要维护更多例外。

  2. 转向高精度入组白名单

    收起 brain、cortical、electrophysiology 等宽泛入口，保留更明确的记录方式、接口短语和实验技术。接受召回范围收窄。

  3. 讨论过 BCI 改名，最终保留现有字段

    BCI 无法概括全部保留内容：睡眠脑电、fMRI 或钙成像不一定属于脑机接口。用户最终明确：维持 science_domains: ["neuroscience"]，只收紧入组关键词。

  4. 删除全部出组关键词

    最终实现仅检查正向入组规则；任何旧出组短语都无法再否决整条记录。MEG、ECoG 的歧义通过入组条件中的技术搭配处理。

名称与覆盖范围分开理解：neuroscience 仍是领域标签；当前关键词只是保守的发现入口。未命中意味着没有满足这套规则，不能据此断言该记录与神经科学无关。
03 / Final rules

保留明确证据，移除宽泛入口。

类别实际保留内容入组方式
记录与影像EEG、sEEG、fMRI、fNIRS；electroencephalograph*、electrocorticograph*、magnetoencephalograph*直接命中，缩写带词边界
需要消歧的缩写ECoG + EEG / signal / recording / electrode / data / based；MEG + EEG / data / recording / signal / source / study / system / sensor缩写须与规定词相邻
接口与硬件BCI、brain-computer interface、brain-machine interface、brain-to-text / speech 等指定短语、brain2X、neural interface、neuroprosthe*、Utah array明确接口或硬件词
范式与实验技术SSVEP、P300、spike sorting、spike train(s)、connectome*、calcium imaging、optogenetic*具体范式或技术词

* 表示实现中的词干匹配。此表概述工作区代码；精确拼写与分隔符范围以 science_domains.py 为准。

已移除的宽泛入口

brain、neuroscience、neurobiology、neuroimaging、cortical、intracranial、hippocampal、prefrontal、electrophysiology、neural activity、neural signals、裸 motor imagery 等，均不再独立触发入组。

一处审计后保留的入口

NeuroTechX/moabb 的摘要只有 “Mother of All BCI Benchmarks”。删除裸 BCI 会丢掉这条明确记录，因此保留带词边界的 bci。当时的全量雷达记录扫描未发现它造成的歧义。

05 / Evidence & scope

收紧命中范围，保留可追溯的边界。

  • 审计范围：58 个快照、10,161 个唯一雷达发现记录；标签命中由 107 条收紧至 46 条。这些计数衡量雷达发现记录，不是 benchmark catalog、论文或模型的数量。
  • 验证记录：最终改动后，science_domains、query_surfaces、snapshots 三组相关测试共 107 项通过；git diff --check 通过。
  • 实际修改：仅调整 入组规则与相关测试。用户要求先人工查看，修改未提交 Git commit。
  • 规则的作用：打领域路由标签，不改变评分；没有标签的记录仍存在于原始语料中，历史快照没有因此被删除或改写。
这些结果还没有证明什么？

命中数量减少不等于准确率提高了多少；讨论中没有建立完整人工标注集，也没有测出 precision 或 recall。关键词匹配仍可能误标，MEG / ECoG 搭配词也不是完整的语义理解。当前没有出组机制，因此明确技术词出现在否定、对比或背景介绍中时，仍可能触发标签。

早期估算曾得到 43 条；最终实现保留 BCI 和少量明确实验技术后为 46 条。初审的 122 项测试与修改后的 107 项测试属于不同版本的测试集合，不能用数量差推断质量。全文数字保留为讨论证据，不随远端代码或数据更新而自动变化。
